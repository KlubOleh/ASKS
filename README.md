# ASKS (Архітектура спеціалізованих комп'ютерних систем)

Репозиторій призначений для виконання лабораторних та практичних робіт з дисципліни **«Архітектура спеціалізованих комп'ютерних систем»** (Національний університет «Львівська політехніка»).

## 📌 Про проект
Цей репозиторій містить матеріали, завдання та звіти до лабораторних робіт, зокрема базові налаштування системи контролю версій Git та роботи з платформою GitHub.

## 🛠️ Використані інструменти та технології
* **Git** — система контролю версій для відстеження змін у коді.
* **GitHub** — веб-платформа для хостингу репозиторіїв та спільної розробки.
* **Командний рядок (Terminal / CMD)** — для виконання git-команд.

## 📂 Структура репозиторію
* `README.md` — опис репозиторію та проєкту.
* Додаткові файли та лабораторні звіти додаються в процесі виконання завдань.
